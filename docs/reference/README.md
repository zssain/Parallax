# Repository structure

This repo will become **Parallax**, a Java 21 / Spring Boot credit decisioning platform.
Nothing has been built yet — the folders below hold the planning inputs.

## `build-pack/`
The prompts used to build the project. Run them **in order, one per session**,
starting with `00-start-here.md`. Each file is a numbered, self-contained build
step (`01-foundation.md` … `23-release.md`). Prompts cross-reference each other by
number (e.g. "Prompt 02"), not by filename.

## `brand/`
Logo and icon assets for the web UI (added later): favicons, app icons, symbols,
lockups, and wordmarks (light / dark / navy / white variants).

## `docs/reference/`
- `parallax-build-spec-v0-hindsight-name.pdf` — the original build spec. It uses
  the old project name **"Hindsight"**; the project is the same one, now called
  **Parallax**.
- `parallax_prototype.html` — the clickable prototype of the product.
